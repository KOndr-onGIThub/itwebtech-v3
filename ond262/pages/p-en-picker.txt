Picker — logistics control system
An app for picking parts from the warehouse to the assembly line
Book a consultation
Picker controls the process of pulling parts from the warehouse and delivering them to the assembly line. It guides the worker step by step on screen, supports barcode scanners, tracks operation time, and gives the team leader a real-time overview. Built for the shop floor.
Challenge
Picking has to run fast and without errors — a mistake means a trip back to the rack, a delay, and a stalled line. Toyota's old "paper checklist" couldn't keep up and gave supervisors no visibility. The team needed a system that guides the worker and lets the supervisor see what's happening.
Solution
A web application with a worker interface (instructions, manual navigation, barcode scanner, timer), a monitoring dashboard for the supervisor, and an admin section for process configuration. It runs in portrait or landscape to match the floor situation. I added in-app issue reporting so the worker doesn't have to run and report verbally.
Result
The client gained a control system that keeps the pace and gives the supervisor visibility at the same time. Workers aren't alone — the app guides them, records work, and captures issues. Process configuration sits in admin, so the system can adapt without developer involvement.
